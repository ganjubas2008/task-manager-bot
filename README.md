# Telegram-бот напоминаний

Русскоязычный бот создает напоминания из обычного текста, уточняет неоднозначное время, просит подтвердить каждую задачу, хранит данные в SQLite и отправляет уведомления после перезапуска процесса.

## Возможности

- даты: сегодня, завтра, послезавтра, дни недели, `15/07`, `15.07`, `15-07`, названия месяцев;
- время: `19:00`, `19 00`, `19.00`, `7 утра`, `7 вечера`, полдень и полночь;
- относительное время: через несколько минут, часов или сутки;
- обязательное уточнение для неоднозначного времени вроде `6:35`;
- OpenAI как резервный parser для разговорных конструкций;
- единый часовой пояс для всех задач — МСК (`Europe/Moscow`);
- проверка даты, времени и прошлого времени;
- обязательное подтверждение кнопками `Да`, `Нет`, `Изменить` перед записью задачи;
- полностью ручное редактирование текста, даты и времени без parser backend;
- список активных напоминаний и удаление кнопкой с обновлением списка на месте;
- SQLite как источник истины и восстановление активных напоминаний после перезапуска;
- физическое удаление задачи из базы сразу после успешной отправки уведомления.

Все сообщения пользователю написаны по-русски.

## Запуск

Нужен Python 3.11 или новее. Внешних библиотек нет.

1. Скопируйте `.env.example` в `.env` и заполните ключи.
2. Запустите проверки:

   ```bash
   cd /home/bot/telegram_hello_bot
   python3 -m unittest discover -s tests -v
   ```

3. Проверьте доступ к внешним API:

   ```bash
   python3 -m reminder_bot.smoke
   ```

   Расширенная differential-проверка обоих parser backend выполняет несколько
   реальных запросов к OpenAI и поэтому включается явно:

   ```bash
   RUN_LIVE_OPENAI_TESTS=1 python3 -m unittest tests.test_differential_live -v
   ```

4. Запустите бота:

   ```bash
   python3 bot.py
   ```

Для постоянной работы процесс следует запускать через `systemd`, Docker или другой диспетчер процессов.

## Работа с ботом

После `/start` можно сразу писать задачу:

```text
концерт завтра в 7 вечера
снять стирку 15/07 в 6:35
позвонить маме через 2 часа
встреча в пятницу в 15:00
```

Перед сохранением бот покажет:

```text
Создать задачу: Смотреть видео на итальянском
Срок: 07.07.2026 19:20 (МСК)
```

И предложит кнопки `Да`, `Нет`, `Изменить`. После нажатия `Да` ответ будет таким:

```text
✅ Задача создана: Смотреть видео на итальянском
Срок: 07.07.2026 19:20 (МСК)
```

Кнопка `Изменить` открывает отдельное ручное меню:

- `Текст` — следующее сообщение целиком становится новым текстом задачи;
- `Дата` — ввод строго в формате `ДД.ММ.ГГГГ`;
- `Время` — ввод строго в формате `ЧЧ:ММ`, без трактовки утра или вечера;
- `Готово` — возвращает к финальному подтверждению.

Ручные значения не передаются ни rule-based parser, ни OpenAI. После удаления
задачи сообщение со списком обновляется на месте, поэтому удалённая кнопка
сразу исчезает и повторно нажать её нельзя.

Команды:

- `/reminders` — список активных напоминаний;
- `/cancel` — отменить текущее уточнение;
- `/help` — справка.

## Архитектура

```text
Telegram → BotApplication → HybridParser
                              ├── RuleBasedParser
                              └── OpenAIParser
                         → Validation → ReminderService → SQLite
```

Parser только возвращает `ParseResult`. Проверка и создание напоминания находятся в отдельных слоях. OpenAI не имеет доступа к Telegram и базе данных.
