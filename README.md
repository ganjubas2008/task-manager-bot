# Telegram-бот напоминаний

Русскоязычный бот создает напоминания из обычного текста, уточняет только неоднозначные данные, хранит задачи в SQLite и сопровождает их до выполнения.

## Возможности

- даты: сегодня, завтра, послезавтра, дни недели, `15/07`, `15.07`, `15-07`, названия месяцев;
- время: `19:00`, `19 00`, `19.00`, `7 утра`, `7 вечера`, полдень и полночь;
- относительное время: через несколько минут, часов или сутки;
- обязательное уточнение для неоднозначного времени вроде `6:35`;
- OpenAI как резервный parser для разговорных конструкций;
- единый часовой пояс для всех задач — МСК (`Europe/Moscow`);
- проверка даты, времени и прошлого времени;
- автоматическое создание понятной задачи с кнопками `Отменить` и `Изменить`;
- полностью ручное редактирование текста, даты и времени без parser backend;
- список активных напоминаний и удаление кнопкой с обновлением списка на месте;
- SQLite как источник истины и восстановление активных напоминаний после перезапуска;
- кнопки `Сделано` и `Позже` прямо в первом уведомлении;
- отложенное напоминание через 15 минут, час или до завтра;
- повтор несделанной задачи каждый день в то же время;
- повторные уведомления с действиями `Сделано`, `Позже`, `Неактуально`;
- единая утренняя проверка незакрытых задач в 08:45 МСК;
- журнал ответов и немедленное скрытие выполненных и неактуальных задач из активного списка.

Все сообщения пользователю написаны по-русски.

## Запуск

Нужен Python 3.11 или новее. Внешних библиотек нет.

1. Скопируйте `.env.example` в `.env` и заполните ключи.
   Время утренней проверки можно изменить через `DAILY_REVIEW_TIME=08:45`.
2. Запустите проверки:

   ```bash
   cd /home/bot/telegram_hello_bot
   python3 -m unittest discover -s tests -v
   ```

3. Проверьте доступ к внешним API:

   ```bash
   python3 -m reminder_bot.smoke
   ```

   Расширенная differential-проверка обоих parser backend выполняет несколько
   реальных запросов к OpenAI и поэтому включается явно:

   ```bash
   RUN_LIVE_OPENAI_TESTS=1 python3 -m unittest tests.test_differential_live -v
   ```

4. Запустите бота:

   ```bash
   python3 bot.py
   ```

Для постоянной работы процесс следует запускать через `systemd`, Docker или другой диспетчер процессов.

## Работа с ботом

После `/start` можно сразу писать задачу:

```text
концерт завтра в 7 вечера
снять стирку 15/07 в 6:35
позвонить маме через 2 часа
встреча в пятницу в 15:00
```

Если дата и время понятны, бот сразу сохранит задачу:

```text
✅ Задача создана: Смотреть видео на итальянском
Срок: 07.07.2026 19:20 (МСК)
```

Под сообщением будут кнопки `Отменить` и `Изменить`. Поэтому дополнительное
подтверждение не требуется, а ошибку можно исправить одним нажатием. Бот задаёт
вопрос только при действительно неоднозначной дате или времени.

Кнопка `Изменить` открывает отдельное ручное меню:

- `Текст` — следующее сообщение целиком становится новым текстом задачи;
- `Дата` — ввод строго в формате `ДД.ММ.ГГГГ`;
- `Время` — ввод строго в формате `ЧЧ:ММ`, без трактовки утра или вечера;
- `Готово` — сразу сохраняет изменения в существующей задаче.

Ручные значения не передаются ни rule-based parser, ни OpenAI. После удаления
задачи сообщение со списком обновляется на месте, поэтому удалённая кнопка
сразу исчезает и повторно нажать её нельзя.

## Выполнение и повтор задач

В первом уведомлении есть кнопки `Сделано` и `Позже`. `Позже` раскрывает только
три коротких варианта: через 15 минут, через час или завтра. Короткая отсрочка не
меняет исходное время ежедневного повтора. Если ничего не нажать, задача
остаётся активной и на следующий день:

- попадает в одну компактную утреннюю проверку в `DAILY_REVIEW_TIME` (по умолчанию
  08:45 МСК);
- снова приходит в собственное запланированное время.

В повторном уведомлении доступны `Сделано`, `Позже` и `Неактуально`. В утренней
проверке остаются три коротких ответа:

- `Сделано` — задача получает статус выполненной и исчезает из активных;
- `Ещё нет` — ответ записывается, задача остаётся активной;
- `Неактуально` — задача закрывается без отметки о выполнении и больше не приходит.

Бот хранит выполненные задачи и историю ответов в SQLite для учёта, но не
показывает закрытые задачи в обычном списке. Утренняя проверка отправляется
только один раз в течение утреннего окна; поздний перезапуск процесса не создаёт
неуместное сообщение «Доброе утро» днём.

Команды:

- `/reminders` — список активных напоминаний;
- `/cancel` — отменить текущее уточнение;
- `/help` — справка.

## Архитектура

```text
Telegram → BotApplication → HybridParser
                              ├── RuleBasedParser
                              └── OpenAIParser
                         → Validation → ReminderService → SQLite
```

Parser только возвращает `ParseResult`. Проверка и создание напоминания находятся в отдельных слоях. OpenAI не имеет доступа к Telegram и базе данных.

## Безопасность

`.env` и база данных исключены из Git. Никогда не публикуйте реальные ключи. Если ключ уже попал в открытый файл или историю Git, перевыпустите его у соответствующего провайдера.
